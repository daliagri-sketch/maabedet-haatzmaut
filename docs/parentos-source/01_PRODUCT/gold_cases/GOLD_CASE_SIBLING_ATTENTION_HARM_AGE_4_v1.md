# GOLD CASE — SIBLING ATTENTION + REPEATED HARM / AGE 4
**Status: APPROVED — 02.05.2026**
**Version: v1**

## Use as reference for:
- אחים — תשומת לב לתינוק / גיל 4
- פגיעה חוזרת שנראית "מקרית"
- Safety first — עצירת פגיעה לפני הסבר
- No reward after harm — לא נותנים תשומת לב מתוך הפגיעה
- Stop harm before explanation
- Parent pattern differentiation (לופ / מ-0-ל-100 / רק_הפעם / ויתור_שקט)

---

## Scenario

**Child:** אלמה, בת 4
**Sibling:** עדן, בת שנה וחצי
**Arena:** אחים — תשומת לב הורה
**Task:** קבלת תשומת לב הורה בלי לפגוע באחות
**Child state:** פוגעת "בטעות" — מפילה / שופכת / פועלת — כשעדן מקבלת תשומת לב
**Resistance type:** covert repeated aggression during sibling attention
**Trigger:** הורה פונה לעדן

**Development (shared):**
- capable_of: לבקש מקום במילים פשוטות עם תיווך / לחכות רגע קצר עם החזקה ברורה
- not_ready_for: לווסת לבד קנאה חזקה / לראות תשומת לב לאחות בלי להציף תגובתיות
- partial_success: אומרת "גם אני" במקום לפעול בגוף
- recommended_scaffold: level 3 / language_level: max_words 5

**Canonical rule (locked):**
- קודם עוצרים פגיעה
- קודם מטפלים בנפגע
- תשומת לב לאלמה לא מגיעה מיד אחרי הפגיעה
- אחר כך — מחזירים את אלמה לדרך אחרת לבקש מקום

## PATTERN 1 — לופ

```
situation_reflection:
  עדן קיבלה תשומת לב.
  אלמה פגעה בה שוב.

child_translation:
  אלמה מיד נכנסת לתמונה.
  היא לא יודעת לבקש מקום
  בלי שמישהו ילמד אותה איך.

parent_reflection:
  אתה מסביר לה שוב למה לא לפגוע.
  ועוד פעם.
  ומחכה שהפעם היא תבין.

inner_anchor:
  בת 4 לא לומדת מהסבר.
  היא לומדת מה שקורה אחרי הפגיעה.
  כל הסבר נוסף הוא תשומת לב —
  שזה בדיוק מה שהיא חיפשה.

say:
  לא פוגעים בעדן.

self_action:
  לא מסבירים.
  עוצרים את הפגיעה.

child_action:
  משפט אחד — שקט.
  קודם מטפלים בעדן.
  אחר כך מחזירים את אלמה לדרך אחרת לבקש מקום.

resistance_response:
  אם היא פוגעת שוב —
  עוצרים את היד.
  מרחיקים אותה מעדן.
  ללא הרצאה.

meaning:
  ככה היא לומדת
  שפגיעה לא מביאה את תשומת הלב שהיא מחפשת.
  ויש דרך אחרת לבקש מקום.

reflection:
  עצרת את הפגיעה.
  ולא הפכת את זה להרצאה.
  זה השינוי.

flag: null
```

  זה השינוי.
